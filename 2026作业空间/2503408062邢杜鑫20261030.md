# 用例描述：瑞幸咖啡小程序修改用户信息

| 项目 | 内容 |
| :--- | :--- |
| **用例名称** | 修改用户信息（密码/用户名） |
| **参与者** | 瑞幸咖啡小程序注册用户 |
| **前置条件** | 用户已成功登录瑞幸咖啡小程序 |
| **后置条件** | 系统更新用户数据库，提示修改成功 |

**主事件流：**
1. 用户在个人中心页面点击“设置”或“账户信息”；
2. 用户选择“修改密码”或“修改用户名”；
3. 系统要求用户输入原密码进行身份验证；
4. 用户输入新密码（或新用户名）并确认提交；
5. 系统验证通过，更新后台数据库并弹出“修改成功”提示。
