## 一、GitHub 运营主体与持久化运营模式

GitHub 日常运营主体为 **GitHub, Inc.**，2018 年被微软收购，作为微软旗下独立子品牌运营，由 GitHub 原有团队负责平台运维、产品迭代、社区管理；底层基础设施依托微软 Azure 云。GitHub 属于商业 SaaS 平台，并非公益项目。

### 盈利来源（支撑平台长期运行）

1. 企业 / 团队订阅：GitHub Team、GitHub Enterprise（企业云端 / 本地私有化部署），是稳定基础现金流；
2. GitHub Copilot：AI 代码助手订阅，近年增长最快的收入板块；
3. 按量计费增值服务：GitHub Actions、Codespaces、Packages 超额资源计费、高级代码安全扫描；
4. 其他：GitHub Marketplace 应用佣金、GitHub Sponsors 赞助分成等。

> 
> 免费公开仓库、GitHub Pages 采用**免费增值 Freemium**策略：吸引开发者、师生搭建生态，免费用户的服务器与存储成本，由企业大客户与付费功能收入补贴。免费并非无限制，存储、带宽、CI 运行时长存在配额。

## 二、个人免费账号：私有仓库规则

✅ **私有仓库数量：无上限，可以创建无限多个私有仓库**（2019 年取消私有仓库个数限制）
✅ 私有仓库协作者人数无上限

⚠️ 核心限制（个人免费版 GitHub Free）

1. 存储：**全部仓库（公有 + 私有）Git 仓库合计上限 10GB**；Packages 包存储免费额度 500MB；GitHub Actions 每月 2000 分钟免费时长；
2. 功能限制：**私有仓库不能直接启用 GitHub Pages**；缺少高级分支保护、高级安全扫描、优先技术支持等 Pro 专属功能；

> 
> 瓶颈不是仓库数量，而是文件总容量，大量高清图片、扫描件、PDF 会快速耗尽存储空间。

### GitHub Pro（个人付费版，约 7 美元 / 月）

私有仓库数量同样不限；解锁私有仓库 GitHub Pages、高级安全、分支保护等全部个人高级功能。

## 三、教学场景实操提示

1. 免费个人账号可新建大量私有教材仓库，但私有库无法直接部署网页；
2. 想要网页展示，二选一：
   - 方案 A：仓库设置为**公开仓库**，直接启用 GitHub Pages；
   - 方案 B：升级 GitHub Pro，私有仓库开启 Pages；
3. 存放碑帖大图、档案扫描件时，留意总存储容量，避免超出 10GB 限额。

## 四、极简小结

> GitHub 由微软旗下 GitHub 团队运营，依靠企业订阅、Copilot、云资源增值服务维持平台运转。
> 个人免费账号私有仓库**数量不限**，约束来自总存储容量与功能权限；免费私有库不能直接开启 GitHub Pages。
